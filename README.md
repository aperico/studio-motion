# Studio Motion

One offline HTML file for planning a repeating training week. Download `index.html`
and open it in a browser. No server, install, sign-in, trackers, or external assets.

## Use it

- It opens on **today** in your device's local time. Pick another weekday to name
  and edit that day's workout. Leave days unplanned or explicitly mark rest.
- Filter the illustrated library by muscle group or by machine, cable, dumbbell
  (halteres), barbell, and bodyweight. Use the start/end poses as simplified
  movement cues, not as a substitute for instruction. **Previous/Next exercise**
  walks through the selected day's workout. Set reps or holds per side where shown.
- **Auto Create Training** previews a repeatable suggestion for the selected day
  using the chosen equipment, focus, and session size. It favors combined moves
  before isolation, suggests editable sets/reps (or holds) and rest, and leaves
  load unset. Neighboring primary muscle groups are used to suggest variety or
  recovery, not to forbid edits. There is no requirement to train every day.
- Use **Print / save PDF** for a printable copy of the selected day.

## Private storage and backups

The browser stores the weekly plan locally when storage is available. Existing v1
sessions at the same browser file location go to **Saved workouts** without
deleting the old storage. Copy one to any weekday. To move to another browser or
file path, export a JSON backup from the old copy, then import it in the new copy.
This version imports v1 and v2; it fills vacant days and keeps conflicts as saved
copies. Replacement and removal of scheduled workouts are explicit. Do not commit
backup files or real training data.

The exercise sketches and text are original and simplified. The generator is a
general planning starting point, not individualized coaching. See [CDC adult
activity guidance](https://www.cdc.gov/physical-activity-basics/guidelines/adults.html),
[CDC on muscle-strengthening activity](https://www.cdc.gov/physical-activity-basics/adding-adults/what-counts.html),
and [AHA on recovery between strength sessions](https://www.heart.org/en/healthy-living/exercise-and-physical-activity/fitness-basics/strength-and-resistance-training-exercise).
