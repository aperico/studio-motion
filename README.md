# Studio Motion

A single-file workout planner with an exercise library and animated movement cues.

Download `index.html` and open it in a browser. There is no install, server, or account. Choose a movement, add it to a workout, and adjust the sets and repetitions. Use **Print / save PDF** for a printable copy.

Sessions are stored in the browser when local storage is available. Use **Backup and restore** to export or import your sessions as JSON. Keep backups private and out of Git; downloading the app does not transfer your sessions to another device.
